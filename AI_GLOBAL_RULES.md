# AI Global Tool-Use Rule

This project follows the user's global AI tool-use rule:

1. For every task, first identify all relevant free tools, integrations, APIs, libraries, open-source projects, and other free capabilities that could materially help.
2. Prefer and use relevant free options before paid alternatives.
3. If multiple relevant free tools can improve the result, use them rather than arbitrarily limiting the workflow to one tool.
4. If a required permission, account connection, credential, approval, or access level is missing, ask the user for the required access/permission instead of bypassing it.
5. Do not purchase, subscribe to, or use a paid service when a suitable free alternative is available.
6. Apply this rule to development, testing, research, deployment, design, automation, debugging, and maintenance.
7. When a free tool is relevant but unavailable, state what access is needed and continue with other available free tools where possible.
